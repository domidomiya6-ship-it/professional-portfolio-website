# Domiya Mayilalakan — Professional Portfolio Website

A responsive personal portfolio website built for the SAD (System Analysis and Design) course assignment at the University of Vavuniya, Faculty of Technological Studies, Department of ICT.

**Live site:** [https://domidomiya6-ship-it.github.io/professional-portfolio-website/]

## About

This site showcases my education, technical skills, projects, and experience as a BICT undergraduate, and gives visitors a way to view/download my CV and get in touch.

## Sections

- Home — introduction and quick navigation
- About — professional summary and career objective
- Skills — technical and design skills with proficiency indicators
- Services — Web Development, UI/UX Design, Software Development
- Projects — filterable project cards (Web / Design / Group Project)
- Experience & Activities — leadership and volunteer roles
- Education — academic background
- Certifications — courses and certificates
- Contact — contact form, email, LinkedIn, GitHub

## Tech Stack

- HTML5, CSS3, vanilla JavaScript (no framework, no build step)
- Google Fonts (Fraunces, Inter)
- Deployed via GitHub Pages

## Features

- Fully responsive, mobile-first layout
- Light/dark mode toggle
- Scroll-reveal animations and hover effects
- Filterable project gallery
- Frontend contact form (connect a service like Formspree to make it functional)

## Running Locally

No build step required — just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
# then visit http://localhost:8080
```
